# 简单 Python 聊天室

使用 Python 标准库运行的网页聊天室，无需安装第三方依赖。支持多个浏览器同时聊天、昵称、消息时间和每秒自动刷新，适配手机屏幕。

## 运行

需要 Python 3.9 或更高版本。在仓库目录运行：

```bash
python3 chat.py
```

在本机浏览器打开 `http://127.0.0.1:8000`。打开两个窗口，输入不同昵称即可聊天。

如果要在可信局域网内聊天：

```bash
python3 chat.py --host 0.0.0.0 --port 8000
```

其他设备通过运行电脑的局域网 IP 和端口 8000 访问。可能需要允许该端口通过系统防火墙。按 Ctrl+C 停止服务。

## 使用范围

- 所有人共享一个聊天室，保留最近 100 条消息，重启后清空。
- 昵称最多 20 字，消息最多 500 字。
- 这是学习示例，没有账号验证、私聊、持久化或 HTTPS，适合本机和可信局域网，不适合直接暴露到公网。
- `hello.py` 是先前的问候程序，可以单独运行。
